# WHARIS — Kalkulator Waris Islam

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![React](https://img.shields.io/badge/React-18-61dafb?logo=react)](https://react.dev)

Kalkulator waris (faraidh) Islam sesuai syariat — hitung pembagian harta warisan berdasarkan Al-Quran dan fiqih Islam. Gratis, tanpa login, data tersimpan lokal.

**Live:** https://wharis.pages.dev

---

## Fitur

- ⚖️ **Faraidh Calculator** — Hitung pembagian waris sesuai syariat Islam
- 👨‍👩‍👧 **Ahli Waris Lengkap** — Suami/istri, anak laki/perempuan, orang tua, saudara
- 📋 **Rincian Lengkap** — Tampilkan bagian (ahlul furudh), ashobah, dll
- 🖨️ **Export** — Cetak/simpan hasil perhitungan
- 📱 **Mobile First** — Dioptimalkan untuk HP
- 🌐 **Offline** — Semua kalkulasi di browser

---

## Quick Start

```bash
git clone https://github.com/alfindigital/wharis.git
cd wharis
npm install
npm run dev
npm run build
```
